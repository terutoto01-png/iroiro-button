# いろいろボタン

子どもが押して遊べるボタンを集めました。1ページにつきボタンが1つあります。HTML と JavaScript だけで動きます。

- `index.html` … メニュー
- WebGPU を使うページ: はなび・にじ・ぷるぷる・うちゅう など
- HTML-in-Canvas API（実験的な機能）を使うページ: ぶんしん・ばらばら・ころころ
  - Chrome の実験フラグ `canvas-draw-element` を有効にしないと動きません
- 音はすべて Web Audio で作っています。音量は右上のボタンで切り替えられます

## PWA（オフライン対応）

GitHub Pages のまま、プログレッシブ Web アプリとして動作します。

- ホーム画面に追加できる
- 一度開いたページはオフラインでも遊べる
- 更新があると「🔄 あたらしくなったよ」と表示され、タップで再読み込み

### 更新するときの注意

Service Worker のキャッシュを正しく更新するため、共通ファイルを変更したら以下を忘れずに更新してください。

1. `common.css` / `common.js` などの URL にある `?v=` の数字を上げる
2. `sw.js` 内の `CORE_CACHE` のバージョン番号を上げる
3. `sw.js` 内の `CORE_ASSETS` 配列の `?v=` も同じ数字にする
